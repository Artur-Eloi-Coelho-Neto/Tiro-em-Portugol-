# 🔫 Tiro Portugol V4.0

Jogo de tiro por turnos feito em Portugol puro, inspirado em Free Fire,Pugb,Battle Royale 
Criado em Portugol

### 🎮 Modos de Jogo
1. **Partida Única** ⚡ - X1 rápido contra o bot
2. **Melhor de 3** 🏆 - MD3 estilo ranqueada. Primeiro a fazer 3 BOOYAH vence

### 🧊 Mecânicas
- **HUD só com emojis** - Interface limpa igual mobile 📱
- **Parede de Gelo** - Bloqueia dano e te protege da zona
- **Correr dá +1 Gelo grátis** - Rotacionar = vantagem tática
- **Granada 💣** - 50 de dano + quebra colete
- **Cogumelo 🍄** - Cura instantânea de 50 HP
- **Águia do Deserto** - Turno par = HEADSHOT 90, Turno 6/12/18 = CAPA 999
- **Loot por turno** - T2=AK, T4=Colete, T6=Águia, T8=Gelo, T10=Doze

### ▶️ Como Rodar
Copie,cole e execute em PORTUGOL
